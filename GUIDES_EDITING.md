# Редактирование гайдов (YAML)

Данные хранятся в `data/guides.yml`.

## Добавить категорию
1) В конец файла добавьте новый блок:

```yaml
- category: "Название категории"
  items: []
```

2) Затем добавьте записи в `items` (см. ниже).

## Добавить гайд в существующую категорию
Найдите нужный блок `category` и добавьте элемент в `items`:

```yaml
- category: "Текстовые гайды"
  items:
    - name: "Название гайда"
      description: "Короткое описание"
      author:
        name: "Имя автора"
        url: "https://пример-ссылки-на-автора"
      link: "https://ссылка-на-гайд"
```

## Добавить разделитель внутри категории
Разделитель позволяет визуально разбить гайды внутри одной категории на подгруппы:

```yaml
- type: "separator"
  text: "Текст разделителя"
```

## Пустая категория
Если гайдов пока нет:

```yaml
- category: "Промпты"
  items: []
```

## Примечания
- В `name` и `description` можно использовать HTML (например, иконки или ссылки).
- Если у автора нет ссылки, можно оставить `url` пустым: `url: ""`.
- Следите за отступами: YAML чувствителен к пробелам (2 пробела на уровень).
