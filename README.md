# SillyTavern Гайды

Удобный каталог полезных материалов, руководств и ссылок для пользователей **SillyTavern**. Проект представляет собой Single-Page Application (SPA) с быстрым поиском по категориям и адаптивным дизайном.

## О проекте

Этот сайт создан для того, чтобы собрать в одном месте лучшие гайды от сообщества: от базовой настройки до продвинутых техник работы с ИИ-моделями.

**Стек технологий:**
- HTML5, CSS3 (Bootstrap 5)
- Pure JavaScript
- YAML (для хранения данных о гайдах)

## Как предложить изменения?

Если вы знаете полезный гайд, которого еще нет в списке, или хотите обновить существующую информацию, вы можете сделать это двумя способами:

### 1. Pull Request на GitHub
1. Сделайте форк репозитория.
2. Добавьте информацию о новом гайде в файл `data/guides.yml`.
3. Создайте Pull Request с кратким описанием изменений.

### 2. Написать напрямую
Вы можете связаться с автором проекта и предложить свои изменения лично:
